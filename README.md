# Он бы тебе сказал 🗣️

Вечеринка-игра для компании. Игрок наугад получает категорию предмета из своей
комнаты (например «что-то на кухне»), достаёт первый попавшийся предмет и
озвучивает голосом, что этот предмет думает о своём хозяине. Запись длится
10 секунд, после чего клип можно прослушать и «отправить» остальным.

## Игровой цикл

1. Стартовый экран с кнопкой «Достать предмет».
2. Показывается случайная категория предмета.
3. По кнопке «Записать реплику» запрашивается доступ к микрофону, включается
   запись (`MediaRecorder`) с визуализацией звуковой волны (`AnalyserNode`) и
   таймером на 10 секунд. Запись останавливается автоматически.
4. Экран воспроизведения клипа с кнопкой play/pause.
5. Кнопка «Отправить» — пока заглушка, показывает тост «клип готов к отправке».
6. Кнопка «Следующий раунд» — возвращает к шагу 2 с новой случайной категорией.

## Стек

Чистый HTML/CSS/JS, без фреймворков и без шага сборки — специально, чтобы
проект можно было задеплоить на Vercel как статический сайт без конфигурации.

- `index.html` — разметка всех четырёх экранов
- `style.css` — тёмная тема, акценты жёлтый `#F4B942` и розовый `#E8598B`,
  заголовки — Space Grotesk, текст — Inter (Google Fonts)
- `script.js` — вся игровая логика: экраны, категории, запись и
  воспроизведение звука
- `PROJECT_LOG.md` — журнал решений и прогресса проекта для будущих сессий

## Локальный запуск

Работа с микрофоном (`getUserMedia`) требует secure context — `https://` или
`localhost`. Открыть `index.html` напрямую через `file://` может не сработать
в некоторых браузерах, поэтому лучше поднять локальный сервер:

```bash
npx serve .
# либо
python -m http.server 8000
```

Затем открой `http://localhost:<порт>` в браузере (лучше всего — на телефоне,
игра мобильная-первая) и разреши доступ к микрофону.

## Деплой на Vercel

Проект не требует сборки: Vercel определит его как статический сайт
автоматически (Framework Preset: Other / No build step). Output directory —
корень проекта.

Планируется привязка к домену **fruktic.com**.
